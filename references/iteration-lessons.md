# 从实际修改过程提炼的经验

以下是 2026 年 6—7 月柔性电路科研示意图项目的复盘。依据是原对话、当时执行日志及相关脚本；历史失败、当时成功和本轮重新核验分别说明。这里不包含原始聊天全文、个人路径或科研模型。

## 演变路线

最初由 DWG 版图生成二维示意图，随后转为 Blender 可编辑场景；电路布局经过平面组件提取、沿曲面包覆、端部电极暴露、黑色同轴环、透明 PDMS 材质调整。后期重点转向几何：黑色双层薄膜合成环体、透明双层壳重建管壁、双绞纤芯变细并去空心、增加透明封口、缩短黑环、延长纤芯、修复末端旋转及圆截面。

最终认可文件名为 `flexible_circuit_V8_round_solid_twisted_cores_0p60.blend`。已证历史依赖为旧 V4 → V5 → V7 → V8；V6 从 V5 派生，是平行尝试。现存早期脚本有过修改和分支，不能拼成完整的一键从零复现链。

## 失败如何变成决策规则

| 真实问题 | 原因与下一次做法 |
| --- | --- |
| 改到了早期场景，覆盖已手工调整的位置 | 根据用户指定文件读取当前对象和预览；历史生成脚本不能替代实际最新场景。 |
| 元件引脚没跨接焊盘，电极被拉成长条 | 先验证平面器件比例、方向和引脚，再整体等比贴合曲面；避免逐轴强行缩放。 |
| 数千条 SVG 线各建一个对象导致流程过重 | 将线段合并为少量 Curve，设置实体上限、重采样和快速预览。 |
| NumPy 映射数组维度不一致 | 中心线/法向/副法向保持 `(N,3)`，逐点角度和半径转为 `(N,1)`，避免广播出巨大二维矩阵。 |
| Blender 材质 socket 名称变化 | 历史 Blender 5.1.1 使用 `Transmission Weight`，不要硬编码旧 `Transmission`；以现场 socket 为准。 |
| 两层黑膜仍像分离薄片 | 两层对象合并不自动生成有厚度实体；保留中心孔，连接内外壁和两端环面。 |
| 透明包层被当作 Curve 处理失败 | 实际对象是 MESH；接手先检查类型，再决定按曲线扫掠或按网格边界重建。 |
| 透明壳布尔后仍不合格 | 当时日志出现边界边 0、非流形边 34。无开口、有体积仍不足以证明拓扑合格。 |
| 想删端盖，却没有任何端盖 | 实际是两组开放曲面；读四个真实边界环，齐端后桥接，而不是依赖名称猜测。 |
| 纤芯逐圈提取中途失败 | 端部与内部环点数曾分别为 34 和 24；先验证拓扑，非均匀网格需其他中心线提取方法。 |
| 拟合中心线后出现分层 | 当时解释认为可能是端部拟合突跳或局部重叠，因果需按具体几何复验；检查中心线连续性和端部渐进过渡，不能只看中段。 |
| 加了端盖仍呈空心 | 原网格保留了贯穿内壁；实心杆应只有连续外表面与两个完整端盖。 |
| “纤芯再长一点”算出增加 0 | 包围盒或错误封口目标不代表需求；使用端盖中心、明确方向和固定增量，并报告实际改变。 |
| 版本越改文件名越长，最后无法保存 | 当时长路径保存失败；把参数放元数据和说明，文件名用 V5/V7/V8 等短标识。 |
| V6 端面平了，但延长段没有继续拧 | 轴向拉伸没有改变螺旋相位；V7 从内部未变形段拟合角速度，按新弧长延续双绞。 |
| V7 弯曲处圆柱被拉扁 | 只平移环中心，没有旋转截面；V8 按局部切线和平行运输标架重建固定半径正圆。 |
| 保存后日志报 Object has been removed | 删除对象后继续访问旧 bpy 对象引用；删除前缓存名称及数值，用新对象引用继续工作。 |
| 旧名 red 的线最后实际上是绿色 | 名称不是当前颜色证据；复制现有材质，避免按名称恢复早期配色。 |

## V8 的具体含义与边界

- 历史 V8 执行日志记录两芯截面各为 64 段，半径约 `0.08001747`、`0.08233332`，边界边与非流形边都为 0。这些参数属于该场景的 Blender 坐标，不能自动解释成毫米。
- `0p60` 沿用当时“累计延长约 0.60”的命名。仅靠最终文件不能反推相对更早模型的真实延长差；要验证差值必须保留或取得对应基准。
- V8 保留 V7 的中心线，重新生成每圈圆截面。每根端盖垂直自身局部切线；旧 V7 的“两芯共用全局 X 平面”不能作为 V8 结论直接继承。
- “边界边 0、非流形边 0、正体积”只描述相关网格检查，不等于整个场景绝无穿模或能够制造。Blender 的实体在这里指闭合表面界定体积，不是内部填充了体单元。
- 壁厚、封口厚度、搭接、缩径百分比和折射率等历史值属于特定示意图的调整参数。新场景应从实际比例和需求确定，不强行套数值。

## 后续复用顺序

先确认用户认可的模型和修改范围，再查对象与拓扑；沿明确的局部坐标实施变化，保存前做数值验证，重新打开后看整体和局部。对已有认可效果只调整目标部分。经验应减少无效返工，不能代替实际检查。
